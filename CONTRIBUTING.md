# Contributing

Thanks for helping keep this list useful.

## Add a resource

Please open a pull request and include:

- Title, year, and a stable link to the paper, dataset, or repository.
- One short sentence explaining why it belongs here.
- Code/license status when available.
- The most specific section where the item fits.

## Curation guidelines

- Prefer primary sources: publisher page, arXiv, official docs, official GitHub/GitLab, Zenodo/Figshare.
- Mark preprints clearly when a peer-reviewed version is not yet available.
- Do not add generic atomistic ML papers unless they are directly relevant to this repository topic.
- Keep descriptions neutral and concise.
