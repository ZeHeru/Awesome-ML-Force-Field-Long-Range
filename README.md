## Introduction

This work focuses on Machine Learning Force Fields with Long-Range Interactions, covering methods for electrostatics, dispersion forces, and other non-local effects. We aim to provide the most comprehensive collection of resources on this topic.

### ✨You are welcome to provide us your work related to ML force fields with long-range interactions.✨

If you discover any missing work or have any suggestions, please feel free to submit a pull request or contact us.

We will promptly add the missing papers to this repository.

###  🍔 Highlight 

[1] We provide a comprehensive collection of methods for handling long-range interactions in machine learning force fields, including electrostatics, dispersion forces, and hybrid approaches.

[2] We organize the content by interaction type and methodology, making it easy to find relevant work for specific applications.

[3] We include both theoretical foundations and practical implementations, with links to code repositories and datasets.
